👋 I'm Rune, an irrepressible Senior Staff Engineer. I design and build multi-tenant calculation and workflow platforms, and I still ship code every week.

## 👀 What I keep thinking about

- **Multi-tenancy without forks.** No client ever settles for vanilla, but no software survives forking on every variation. The design work is finding where that line sits: which variation belongs in configuration, and which belongs in the model.
- **AI agents I don't have to trust.** Most of my hands-on work now goes through AI agents. I'm working towards a zero-trust setup where agents can still work end-to-end on complex stories, so I'm not the human bottleneck but I stay in control.
- **Languages.** I maintain a domain-specific rules language by day. Rust has graduated from "currently learning" to "currently writing".
